# SAFRA Developers — Modern 3D Real Estate Platform

**Crafting Tomorrow's Landmarks** — Luxury real estate website for **SAFRA Developers**, Lahore's premier developer (Est. 2006).

Built with **React + Vite + React Three Fiber + Framer Motion + Tailwind CSS** in a modern Rust/Copper luxury palette.

### Features
- **3D Hero** with interactive Three.js building model (floating, glass facade, terracotta cap)
- **Multipage Routing** (React Router): Home, Projects, Project Detail, About, Contact
- **Modern Rust Theme**: Cream #FFFBF5, Ink #0A0A0B, Rust #C65D2E / #B45309, Copper
- **3D Tilt Cards** on projects with preserve-3d + shine sweep
- **Fully Responsive** with glassmorphism, Framer Motion page transitions
- **Production Ready**: LDA/DHA approved messaging, escrow, booking flows

### Pages
- `/` — Hero, stats, featured projects, why SAFRA, testimonials, CTA
- `/projects` — Filterable portfolio (6 projects)
- `/projects/:id` — Gallery, features, payment plan, brochure form
- `/about` — Story, mission, leadership
- `/contact` — Experience center, WhatsApp, tour booking

### Run
```bash
npm install
npm run dev    # http://localhost:5173
npm run build
```

### Tech Stack
React 18, Vite 5, React Router 6, Three.js + @react-three/fiber + drei, Framer Motion, Tailwind CSS 3, Lucide React
